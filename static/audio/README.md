# 内置哄睡音频

首页 🎵 弹出的选择框里，"嘘嘘声"和"母体子宫音"两项会播放本目录下的本地音频。

## 放置文件

请把音频文件放到本目录，文件名必须是：

- `shush.mp3` — 嘘嘘声（白噪音 / shushing sound）
- `womb.mp3` — 母体子宫音（womb sound / heartbeat + flow）

格式要求：

- 推荐 MP3（小程序 `InnerAudioContext` 兼容性最好），也可用 m4a / aac
- 时长建议 30 秒~ 2 分钟（无缝循环效果最好）
- 单声道、96 kbps 即可，节省包体

## 来源建议

可在以下渠道找到免版税素材：

- freesound.org — 搜 "shushing baby" / "womb sound"
- pixabay.com/sound-effects — 搜 "white noise" / "womb"
- mixkit.co — Free SFX

下载后改名放入本目录即可。如未放置，点击对应选项会提示「内置音频缺失，请放入 static/audio/」。

"自定义录音"项使用的是用户在 App 内自己录的音频，与本目录无关。
